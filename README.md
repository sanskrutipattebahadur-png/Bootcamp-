# Zero Trust Network Access (ZTNA) — BootCamp Project

**Student:** Sanskruti Pattebahadur  
**Program:** Security BootCamp 2026 — BharatCares / IBM SkillsBuild Cyber Security

## Project description
A beginner-friendly Python simulation of a Zero Trust Network Access decision. It checks fictional identity verification, device compliance, and least-privilege resource permissions, then returns ALLOW or DENY with reasons.

## Dataset
No external dataset is required. The notebook contains fictional sample requests for demonstration. It does not use real accounts, passwords, devices, or network traffic.

## Technologies used
- Python 3
- Jupyter Notebook
- Python standard library (`dataclasses`)

## Setup and run
1. Open `SanskrutiPattebahadur_ZeroTrustNetworkAccess.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
2. Run all cells from top to bottom.
3. Review the access decisions and explanations.

## Dependencies
No third-party libraries are required. See `requirements.txt`.

## Limitations
This is an educational simulation only, not a real ZTNA gateway. Do not use it to protect a production network.
